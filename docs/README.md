## Les 3 niveaux d'usage

L'application se prend en main **par paliers** : on peut tout faire au niveau 1, les niveaux
supérieurs ne servent que quand le besoin apparaît.

1. **Débutant — les listes.** Vous rangez vos contacts dans des **listes** et vous envoyez un mailing
   à une liste. C'est suffisant pour la grande majorité des usages.
2. **Intermédiaire — les segments nommés.** Quelqu'un a préparé des **segments** (« Non-répondants
   Lodève », « Élus du canton »…). Vous les appliquez d'un clic, sans rien avoir à paramétrer.
3. **Expert — filtres avancés & sélection.** Vous construisez vos propres critères, vous assemblez une
   **sélection** de travail à la main, vous l'enregistrez comme liste ou vous la mailez.

> L'idée directrice : **la complexité vit dans le nom d'un segment, pas à l'écran de l'utilisateur.**

## Conventions de rédaction

- **Vouvoiement**, comme l'interface.
- **Orienté tâche** : chaque page répond à « comment faire X ».
- **Véracité avant exhaustivité** : chaque bouton/libellé cité existe à l'identique dans l'application.
  Mieux vaut une page courte et juste qu'une page complète et fausse.
- **Zones en construction** balisées `🚧 à venir` : la fonction est prévue mais pas encore là.
- **Synchro** : quand une fonctionnalité est stabilisée, sa page de doc est mise à jour dans la foulée.
